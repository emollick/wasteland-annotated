# How the tarot cards are made

Every card in `art/tarot/` is generated by code; nothing was drawn by hand. This folder is the generator, kept so a card can be changed later without starting over.

- `deck/lib.js` is the engraving toolkit: the 300×520 frame, hatching (with spacing gradients, jitter, broken lines), cross-hatch, stipple, contour lines, drapery folds, black masses with paper slivers (even-odd fills), Voronoi cracked earth, and outlined lettering.
- `deck/fig.js` has the small figure helpers (tubes for limbs).
- `deck/cards/<name>.js` is one card each; the file name is the card's file name and the page's id. Each exports a function that returns a `Card`; read any one of them to see the idiom.
- `deck/build.js` builds cards, publishes them and renders PNGs for looking at.
- `textpath.py` outlines the lettering with HarfBuzz and fontTools; `fonts/` holds the TTFs it needs (EB Garamond and Cormorant Garamond, converted from the @fontsource WOFF files; both fonts are under the SIL Open Font License).
- `render.js` and `sheet.js` render SVGs to PNG with Playwright's Chromium, one card or a contact sheet, in the light or the dark theme.

To rebuild, in a copy of this folder:

    npm install                      # only for the fontsource packages, if the TTFs in fonts/ are missing
    pip install uharfbuzz fonttools  # for textpath.py
    MODE=both node deck/build.js phlebas swallow   # builds, publishes to art/tarot/ (edit DEST in build.js), renders light and dark
    MODE=light NOPUBLISH=1 node deck/build.js phlebas   # build and render only, for looking
    NODE_PATH=<global node_modules with playwright> node sheet.js out.png 3 1.3 light out/a.svg out/b.svg ...

`build.js` expects Playwright to be installed globally (set `NODE_PATH` to its `node_modules`), and `render.js` wraps each SVG in a page whose colours are the palette in `art/STYLE.md`.

Conventions the cards keep: all ink is `currentColor`; never paint the paper colour (a paper fill would hide linework in dark mode); one flat accent per card at most (gold, violet or rust); the numeral is the poem line where the figure first appears; nothing on a card is text but the name and the numeral, and both are paths.
